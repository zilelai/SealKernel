SealKernel CLI Script
=====================
<h1>What is SealKernel CLI Script?</h1>
<p>SealKernel is an "OS-like" CLI program that I made on 13th May 2026. SealKernel can read, write and execute files, contains RPG games, contains ASCII arts, uses rand() function and importantly a "tsastream" function that students can use to see their streaming marks and what classes they go to for the next term (ONLY SPECIFIC SCHOOL). SealKernel was written in C, uses stdio (now most of them are using zlio.h), stdlib, math and more libraries to write it.</p>

Using SealKernel
================
<h4>In CodePad</h4>
<p>Search for SealKernel</p>
<p>Click the one that has the name of SealKernel/SealScript and is made by zilelai</p>
<p>Press the start button to start using it</p>
<p>Note that SealKernel in CodePad has the full versino (includes tty1, tty2 and bootloader)</p>
<h4>Locally</h4>
<h6>Full repository download</h6>
<p>use git clone https://github.com/zilelai/SealKernel/</p>
<p>Then go into that repository and compile everything using gcc/g++ compiler</p>
<p>Then use ./name to run it (note that name is a variable based on what you put when you are compiling)</p>
<h4>Using Downloader</h4>
<p>use git clone https://github.com/zilelai/SealKernel/downloader</p>
<p>Then compile it with cd downloader && gcc downloader.c -o downloader</p>
<p>Then run it with ./downloader</p>
<p>There, based on the steps you can set up your own non-bloated, custom SealKernel with added dependencies/repositories (optional)</p>

You can contribute to SealKernel by forking it or giving an issue in this repositories
Besides this, you can visit zilelai.lab26.my for more info or e-mail zlprojects.sealkernel@gmail.com if you have any problem with SealKernel.

SealKernel also uses the SUDD directory management and ZLIO library. While SUDD directory management library isn't a public repository nor posted in both CodePad and GitHub platforms, ZLIO is and available on both CodePad and GitHub platforms. Additionally, both SUDD and ZLIO library are inside SealKernel (both ttys).
